🎀 使い方ガイド

チアタンブリングロードマップ（v1.3）
📖 目次
1. 参加する（招待コードから） 2. 課題を確認する 3. 完了報告する 4. コーチからの返信を見る

1 コーチに招待してもらう

コーチから 招待URL や 6文字の招待コード（例：BB8JT5）を受け取ってください。LINE・QRコード・印刷物のどれでも届きます。

💡 ヒント：QRコードならスマホのカメラで読み取るだけで参加ページが開きます。

参加の流れ

  1. 招待URLを開く（QRなら自動）
  2. 「Googleでログイン」 または メールアドレスで新規登録
  3. 自分の名前を入力（コーチに表示される名前）
  4. 「このコーチに参加する」を押す → 🎉 完了

2 課題を確認する

アプリのトップ画面（🏠 トップ）を開くと、コーチからの課題が 「📋 マイページ」 カードに表示されます。

  • 未完バッジ：あと何項目残っているかひと目で分かる
  • 右上のメニュー（☰）：いつでもマイページにジャンプできる

マイページに行くと、各課題が カード形式 で表示されます。タイトル・コーチからのメッセージ・期限が確認できます。

3 完了したら「報告」する

各項目（スキルやトレーニング）の右に 「報告」 ボタンがあります。タップして：

  1. 動画URL（任意）：練習を撮った動画のリンク（LINE Keep / Google ドライブ / iCloud 共有 / YouTube どれでもOK）
  2. ひとことコメント（任意）：「10回中7回できた」「足の伸ばし方が難しかった」など
  3. 「✓ 済として送信」 をタップ
💡 動画は送らなくてもOK！「報告」ボタンを押すだけでもコーチに完了が伝わります。動画があるとアドバイスがもらいやすくなります。

4 コーチからの返信を見る

コーチが返信すると、項目に 「💬コーチ返信」 バッジが付きます。

課題カードの下にある 「💬 コーチからの返信 (N件)」 をタップで開くと、コーチのコメントが読めます。

📖 目次
1. コーチアカウントを作る 2. 選手を招待する 3. 課題を出す 4. 提出物を確認・返信する 5. 進捗を一覧で見る

1 コーチアカウントを作る

🎀 コーチダッシュボードへ →

Googleアカウントまたはメールアドレスでログインしたあと、チーム名・指導者名 を入力して登録します。登録すると 6文字の招待コード（例：BB8JT5）が自動発行されます。

2 選手を招待する

ダッシュボード上部の「選手を招待する」エリアから、好きな方法で選手に招待を送ります。

  • 💬 LINEで送る：自動で LINE アプリが開いて、招待文＋URL がプリセットされます。あとは選手を選んで送るだけ。
  • 📋 URLをコピー：他のチャットアプリやメールで送りたい場合
  • 📥 QR画像を保存：SNS や Web に貼る用の PNG をダウンロード
  • 🖨️ 印刷：A4縦の大きいQR＋説明文を印刷。道場・教室に貼っておけます

3 課題を出す

左メニュー「📋 課題を出す」をクリック。

  1. 配布先：全員に配信 / 個別に選ぶ
  2. メニュー：スキル33件＋トレーニング35件から検索＋追加。各項目に「ひとことメモ」も付けられる
  3. タイトル・メッセージ・期限：必要に応じて
  4. 「📤 課題を送信」

送信すると選手のマイページにすぐ届きます。

4 提出物を確認・返信する

左メニュー「📥 提出物」をクリック。未返信件数バッジ がついているので一目で分かります。

  • 選手が出した 動画リンク をタップで開く（YouTube / Drive / LINE どれでも対応）
  • テキストでコメント返信：「踏み切りが良くなった！次は腕の振り上げを意識しよう」など
  • 返信後は 「✏️ 返信を修正」 で再編集可能
  • フィルター：すべて／未返信のみ／返信済み

5 進捗を一覧で見る

左メニュー「📈 進捗一覧」をクリック。

選手 × スキル/トレーニング のマトリクスで、誰がどこまで進んだか色分け表示されます。

  • 🔵 シアン：配布済・未提出
  • 🟡 ゴールド：提出済・未返信
  • 🟢 グリーン：提出＋返信済

セルにマウスを乗せると詳細が表示されます。フィルターで「配布した項目のみ」「全スキル」を切り替え可能。

不具合や要望は 画面右下の 「🐛 不具合報告」 ボタンから送ってください。

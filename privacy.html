プライバシーポリシー

最終更新日：2026年5月26日 ／ 制定日：2026年5月26日
一般社団法人チアタンブリング協会（以下「当協会」）は、当協会が提供するアプリケーション「チア タンブリング ロードマップ」（以下「本サービス」）における、利用者の個人情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

第1条（取得する情報）

当協会は、利用者が本サービスを利用する際に、以下の情報を取得します：

情報の種別取得タイミング取得方法
メールアドレスアカウント登録時利用者の入力／Google アカウント連携
表示名（Google アカウントから取得した名前）Google ログイン時Google アカウント連携
プロフィール画像 URLGoogle ログイン時Google アカウント連携
練習メニュー（利用者が作成した内容）機能利用時利用者の入力
選手情報（名前・絵文字・色などの管理用情報）機能利用時利用者の入力
進捗記録（技ごとの習得状況）機能利用時利用者の入力
利用ログ（アクセス日時、ページ閲覧履歴、機能利用履歴等）本サービス利用時自動取得
端末情報（OS・ブラウザ種別等）本サービス利用時自動取得

当協会が取得しない情報：クレジットカード番号、銀行口座番号、マイナンバー等の機微な個人識別情報。決済機能を将来実装する場合は、外部の決済代行サービスを経由し、当協会自身は決済情報を保持しません。

第2条（利用目的）

当協会は、取得した個人情報を以下の目的で利用します：

  1. 本サービスの提供・運営のため
  2. 利用者からのお問い合わせに回答するため（本人確認を含む）
  3. 利用者に新機能、更新情報、キャンペーン等および当協会が提供する他のサービスの案内のメールを送付するため
  4. メンテナンス、重要なお知らせなど必要に応じたご連絡のため
  5. 利用規約に違反した利用者や、不正・不当な目的でサービスを利用しようとする利用者の特定をし、ご利用をお断りするため
  6. 利用者にご自身の登録情報の閲覧や変更、削除、ご利用状況の閲覧を行っていただくため
  7. 有料プランにおいて、利用者に利用料金を請求するため
  8. サービス改善のための統計分析（個人を特定しない形式に加工した上で実施）
  9. 上記の利用目的に付随する目的

第3条（第三者提供）

  1. 当協会は、次に掲げる場合を除いて、あらかじめ利用者の同意を得ることなく、第三者に個人情報を提供することはありません：
    • 法令に基づく場合
    • 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
    • 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合であって、本人の同意を得ることが困難であるとき
    • 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して、協力する必要がある場合であって、本人の同意を得ることにより当該事務の遂行に支障を及ぼすおそれがあるとき
  2. 前項の定めにかかわらず、次に掲げる場合には、当該情報の提供先は第三者に該当しないものとします：
    • 当協会が利用目的の達成に必要な範囲内において個人情報の取扱いの全部または一部を委託する場合
    • 合併その他の事由による事業の承継に伴って個人情報が提供される場合

第4条（外部サービスの利用）

本サービスは、以下の外部サービスを利用しており、これらのサービスにおける個人情報の取扱いは、各社のプライバシーポリシーに準じます。

外部サービス提供者用途プライバシーポリシー
Firebase AuthenticationGoogle LLC アカウント認証（Google ログイン・メール認証） Google プライバシーポリシー
Cloud FirestoreGoogle LLC 利用者データ（メニュー・進捗等）の保存 Google プライバシーポリシー
YouTubeGoogle LLC 解説動画の配信 Google プライバシーポリシー
Google Analytics for FirebaseGoogle LLC 利用状況の統計分析（個人特定なし） Google プライバシーポリシー
GitHub PagesGitHub, Inc. 本サービスのウェブホスティング GitHub プライバシーポリシー

第5条（保存期間）

個人情報の保存期間は、利用目的の達成に必要な期間とし、不要となった情報は遅滞なく消去します。退会された場合、利用者のアカウントに紐づく個人情報は、合理的な期間内（原則として30日以内）に削除します。ただし、法令に基づき保存が義務付けられている情報については、当該期間を経過するまで保管します。

第6条（個人情報の安全管理）

当協会は、個人情報の漏洩・滅失・毀損の防止その他の安全管理のために、必要かつ適切な措置を講じます。具体的には以下を実施しています：

  • 個人情報を保存する Cloud Firestore のセキュリティルールにより、本人のみが自分のデータを読み書きできるよう制限
  • 通信は HTTPS で暗号化
  • 認証は Firebase Authentication が提供する業界標準の方式を採用

第7条（個人情報の開示・訂正・削除）

  1. 利用者は、当協会に対して個人情報の開示、訂正、追加、削除、利用停止、消去、第三者提供の停止を請求することができます。
  2. 本サービスでは、利用者は自身のアカウント情報・練習メニュー・進捗記録等を、本サービス内の機能を通じていつでも閲覧・編集・削除することができます。
  3. 上記以外の請求や、アカウント全体の削除をご希望の場合は、第10条のお問い合わせ先までご連絡ください。
  4. 当協会は、利用者本人からの請求であることを確認のうえ、合理的な期間内に対応します。ただし、法令に基づき開示等の請求に応じられない場合があります。

第8条（Cookie および類似技術）

本サービスは、利便性向上のため Cookie および類似技術（localStorage 等）を使用します。これらにはアカウントログイン状態の維持、利用設定の記憶、利用状況の分析等の機能があり、個人を特定する情報は含まれません。利用者はブラウザ設定によりこれらを無効化できますが、その場合本サービスの一部機能が利用できなくなる場合があります。

第9条（未成年者の利用について）

本サービスは未成年者も利用可能ですが、未成年者が本サービスを利用する場合、保護者の同意を得たうえで利用してください。当協会は未成年者の個人情報について特に慎重に取り扱います。

第10条（プライバシーポリシーの変更）

  1. 本ポリシーの内容は、法令その他本ポリシーに別段の定めのある事項を除いて、利用者に通知することなく、変更することができるものとします。
  2. 当協会が別途定める場合を除いて、変更後のプライバシーポリシーは、本ウェブサイトに掲載したときから効力を生じるものとします。

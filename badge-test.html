アイコンバッジ テスト

ホーム画面アイコンに赤い数字が出るか確かめます。

いまの状態

端末が対応しているか—
ホーム画面から起動しているか—
通知の許可—
総合判定—

試す

ボタンを押すと結果がここに出ます。

iPhone での手順

  1. このページを Safari で開く（Chromeでは不可）
  2. 下の 共有ボタン → 「ホーム画面に追加」
  3. ホーム画面にできたアイコンから開き直す
  4. このページで ①通知を許可 → ②「3」を出す
  5. ホーム画面に戻ってアイコンに 3 が付いていればOK

Safariのタブで開いたままでは、どの端末でも数字は出ません。
iPhoneは iOS 16.4 以降が必要です。

Android での手順

  1. Chrome で開く
  2. メニュー → 「アプリをインストール」
  3. できたアイコンから開き直す
  4. ②「3」を出す（通知の許可は不要）

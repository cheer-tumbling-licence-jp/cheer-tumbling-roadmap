## 技データの扱い（重要）

- 技の概要・ポイント・注意点・よくあるミス・進め方は **`data/cheer_tumbling_skills.json` で一元管理**。
- アプリ内のモーダル表示はこのJSONを参照（`GUIDE_ID_MAP` / `GUIDE_VARIANT_MAP` でアプリ内IDとJSON IDを対応付け）。
- 編集フォームからは解説文の編集欄を撤去済み。**文章修正はJSONを直接編集**する。
- JSONのIDは英語 snake_case、アプリ内 `skills` 配列のIDはハイフン区切り。

### 🔥 OAuth トークン失効時の復旧手順（恒久メモ）

`youtube/launchd.log` に `invalid_grant: Token has been expired or revoked` が出ていたら：

```bash
rm /Users/don/cheer_tumbling_app/youtube/token.json
cd /Users/don/cheer_tumbling_app/youtube
python3 upload_videos.py --dry-run
# → ブラウザが開く → cheernicpro@gmail.com で承認 → token.json 再生成
```

これは**監督の手が必要**（ブラウザでGoogle承認画面に同意するため）。所要3分。
完了後、当日の `python3 upload_videos.py --limit 6` を手動で1回回せば追いつく。

### ⚠️ 技名一括置換時の落とし穴（恒久メモ）

技名（「立ちバク転」→「バク転」など）を `index.html` や `data/*.json` で一括置換するときは、必ず以下を確認：

1. `const FURIGANA_DICT = {...}` の中に **旧名のキーが含まれていないか** grep する
2. 含まれていれば、置換後に重複キーや読み崩れが発生する
3. 対処：置換前に `FURIGANA_DICT` 内の該当エントリを別途手動修正してから本体置換、または **置換スクリプトで FURIGANA_DICT の行を除外**

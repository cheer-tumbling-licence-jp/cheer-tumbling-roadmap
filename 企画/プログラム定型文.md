# 練習プログラム 定型文（添削用）

「練習プログラム」機能で、プログラムを作るたびに出てくる**決まった文章**の一覧です。

- 技名・トレーニング名は技データから自動で入るので、ここには**含まれません**
- ここにあるのは「**どの技でプログラムを作っても共通で出る文章**」だけ
- ここを直せば、以後すべての生成プログラムに反映されます（毎回直す必要はありません）

## 監督の作業

このファイルの文章を見て、直したいところを **書き換えて保存** する、または「ここをこう直して」と Claude に伝えてください。
Claude がアプリ本体（`index.html` の `PROGRAM_TEXT`）に反映します。

---

## 1. カテゴリ名（各ステーションの種類名）

| キー | 文言 |
|---|---|
| 補助して実施 | 補助して実施 |
| 細分化練習 | 細分化練習 |
| トレーニング | トレーニング（自動で「①」「②」がつく） |
| 仕上げ | 仕上げ（self） |

## 2. 各カテゴリのねらい（カードの 🎯 の文）

**【補助して実施】**
指導者の補助つきで、技の正しい動きと軌道を安全に覚えます。

**【細分化練習】**
技を分解した前段階の動きで、必要な部分の感覚をつくります。

**【トレーニング①②】**
目標の技に必要な筋力・体づくりを行います。

**【仕上げ（self）／指導者が1人のとき】**
練習の最後に、補助なしで通しで挑戦します。危険度の高い技は無理をしないこと。

**【仕上げ（self）／指導者が2人以上のとき】**
2人目の指導者のもとで、補助を減らして通しで挑戦します。

## 3. 技名のうしろにつく補足

| 場所 | 文言 |
|---|---|
| 補助して実施のステーション | （マット・補助あり） |
| 仕上げのステーション | （補助なしで挑戦） |

## 4. プログラム全体の文

**【見出し】**
このプログラムの目的

**【目的の文】** ※「◯◯」は目標の技名に自動で置きかわります
「◯◯」の習得に向けて、補助して実施・細分化練習・トレーニング・仕上げをひと回りで行うサーキット練習です。

## 5. 安全注意文（プログラム下部に表示）

各技の危険度（小・中・大）を確認してください。大の技は必ず指導者の補助・マットつきで。自走ステーションでも反り系・回転系はマットを敷き、不安な選手は指導者ステーションで見てください。指導者は補助ステーションから離れないようにしましょう。

## 補足

- 特定の技だけ専用の文章にしたい場合は「手書きパターン」で上書きできます（例：バク転習得サーキット）。
- このファイルと `index.html` の `PROGRAM_TEXT` は Claude が同期させます。監督はこのファイルだけ見ればOKです。

## 1. エグゼクティブサマリー

「Cheer Tumbling Roadmap」を **フリーミアム型サブスクリプション** で収益化する。

- **市場**：チア×タンブリングの習得ロードマップアプリは直接競合がほぼ不在の **ブルーオーシャン**。
- **最大の武器**：監督が全国 **70チーム以上を直接出張指導** している。広告に頼らず、信頼関係のあるレッスン現場で直接アプリを届けられる。
- **モデル**：無料版（閲覧専用）＋有料サブスク（練習メニュー・進捗管理・カスタマイズ）。
- **転換の鍵**：無料併存型の転換率は2〜5%と低いが、**「全機能おためし → 継続課金」のトライアル型**＋監督の信頼チャネルで転換率を大きく引き上げる。
- **収益見込み**：保守的シナリオで **年間約180万円の継続収益**、トライアル型がうまく回れば **年300万円超**。新規チーム獲得ごとに積み上がる。

## 2. プロダクト現状（監査結果）

自己完結型 HTML アプリ（GitHub Pages 公開）。技約80種・トレーニング約40種を収録。

### 機能一覧

| 区分 | 機能 | タイプ |
|---|---|---|
| タンブリング技 | ロードマップ（リスト／ツリー系譜図表示）、レベル絞り込み、検索、技詳細モーダル（説明・前段階・ポイント・ミス・進め方・バリエーション・USA Cheerバッジ）、YouTube動画埋め込み | 閲覧系 |
| トレーニング一覧 | 4カテゴリ別表示、絞り込み、検索、詳細モーダル | 閲覧系 |
| 練習メニュー | 複数メニュー作成・名称変更・複製・削除、項目追加、ドラッグ並び替え、メモ記入、印刷 | 作成・保存系 |
| 編集モード | 文言編集、並び替え、レベル変更、バリエーション編集、HTMLエクスポート | 作成・保存系 |
| ふりがな表示 | 漢字ふりがなトグル | 閲覧系 |

### 強み
- 閲覧系と作成・保存系がきれいに分離 → **フリーミアムの線引きが容易**。
- YouTube公式動画（32本アップロード進行中）と連動。
- 監督本人＝協会理事・指導歴18年・元体操選手の専門性がコンテンツの裏付け。

### 現状の弱点（収益化に向けて）
- データ保存が `localStorage`（端末内のみ・同期なし・課金強制が技術的に不可）。
- 「進捗トラッキング」機能が未実装（＝有料の目玉になる機能がまだ無い）。
- 認証・決済の仕組みが無い。

## 3. 市場分析

### 3.1 市場規模
- 競技登録者（FJCA系）は約1万人。学校部活・チアスクール・体操/アクロバット教室まで含めた「タンブリングを練習する子ども」の総数はこれを大きく上回ると推定（正確な統計はデータなし＝今後の宿題）。
- 子どもの習い事「ダンス」は人気上昇中（2025-2026調査で6位）。チア／チアダンスはバレエ同等の人気層。

### 3.2 競合（ブルーオーシャン）
- **チア特化のタンブリング習得ロードマップアプリは検索で発見できず、直接競合は事実上不在。**
- 隣接競合：AIスマートコーチ（汎用フォーム解析）、スポテク（学校器械運動ICT教材）、練習ノート系アプリ。いずれも「技の習得順序＝ロードマップ」「チア特化」は持たない。
- → 汎用アプリがチアに横展開する前に、チア特化で深く作り込み **先行者優位** を取る。

### 3.3 価格相場
- 子ども向け学習・教育サブスクの相場：**月額300〜980円**。
- 保護者の心理的上限は **月額約1,000円**。
- チア保護者は既に教室の月謝（数千〜1万円超）を払っている → 補助ツールは **月¥500〜990** が受容されやすい上限。

### 3.4 転換率の知見
- 無料併存型フリーミアム：有料転換率は **2〜5%**（業界の「5%ルール」）。
- **カード登録を伴う無料トライアル型：転換率約30%**。→ 本件はこちらを採用すべき。

## 5. ポジショニング

> **「監督の出張レッスンと出張レッスンの『間』を埋める、家庭・チームの練習ナビ」**

監督の訪問指導は月1回〜数ヶ月に1回。その**空白期間に、選手が「何を・どの順で・どう練習するか」を迷わない**ためのツールとしてアプリを位置づける。

- アプリは監督の指導の **継続装置**。レッスンの価値を高め、選手の上達を加速させる。
- 「アプリでフォローします」は **新規チーム獲得の営業武器** にもなる（本業との相乗効果）。
- アプリ単体の商品ではなく「**監督の指導メソッドのデジタル版**」として売る。

## 6. 収益モデル

### 6.1 料金プラン（叩き台）

| プラン | 対象 | 価格 | 内容 |
|---|---|---|---|
| **無料プラン** | 全員・お試し入口 | ¥0 | ロードマップ閲覧・全動画視聴・ふりがな（=立ち読み） |
| **ファミリープラン** | 保護者・選手 | **月¥800（年¥8,000＝2ヶ月分お得）** | 練習メニュー無制限・進捗トラッキング・選手3人まで |
| **コーチプラン** | 指導者 | **月¥2,000（年¥20,000）** | ファミリー機能＋選手無制限・チーム管理・メニュー配布・印刷教材 |

> 価格は市場リサーチの心理的上限（月¥1,000）を踏まえ、保護者向けは¥800に設定。コーチ向けはプロツールとして¥2,000。監督の価格感（¥900〜2,000）の範囲内。

### 6.2 無料／有料の線引き

| 機能 | 無料 | 有料 |
|---|---|---|
| ロードマップ閲覧（リスト・ツリー） | ✅ | ✅ |
| 技・トレーニング詳細の閲覧 | ✅ | ✅ |
| YouTube動画視聴 | ✅ | ✅ |
| 検索・絞り込み・ふりがな | ✅ | ✅ |
| 練習メニュー作成・保存 | ❌（体験用に1つだけ可） | ✅ 無制限 |
| **進捗トラッキング（要新規開発）** | ❌ | ✅ |
| 編集モード・カスタマイズ | ❌ | ✅ |
| 複数選手の管理 | ❌ | ✅ |
| 印刷教材・限定コンテンツ | ❌ | ✅ |

**有料の目玉＝「進捗トラッキング」**。子どもの成長記録は溜まるほど価値が増し、消したくないから課金が止まらない。これが継続課金の核。

### 6.3 トライアル設計
- レッスン現場で **30日間 全機能おためし** を配布。
- おためし中に保護者が「子どもの進捗記録」に愛着を持つ → 継続率が上がる（機能制限型より体験期限型の方が転換率が高い）。
- おためし終了後、継続したい人だけ課金。

### 6.4 収益予測

前提：70チーム × 平均15名 ＝ 約1,050世帯 ＋ コーチ70名。

| シナリオ | ファミリー転換 | コーチ転換 | 年間継続収益 |
|---|---|---|---|
| 保守的 | 15%（158世帯×¥8,000） | 30%（21名×¥20,000） | 約 **168万円** |
| 標準 | 22%（231世帯×¥8,000） | 40%（28名×¥20,000） | 約 **241万円** |
| 楽観（トライアル型奏功） | 30%（315世帯×¥8,000） | 50%（35名×¥20,000） | 約 **322万円** |

※ いずれも **継続収益**。新規チーム獲得ごとに上積み。

## 7. マーケティング・販売戦略

### 7.1 主軸：70チーム直接チャネル
- 監督が出張レッスンの度に、現場でアプリを紹介・トライアル配布。
- **広告費ゼロ**・信頼関係ベースで成約率が高い。
- 「数千人の個人説得」ではなく「70回の現場提案」で済む。

### 7.2 販売の流れ（レッスン現場フロー）
1. レッスン中に「練習メニューはこのアプリで」と実演。
2. その場でQRコードを配り、全員に **30日トライアル** を案内。
3. レッスン後、コーチ経由で保護者LINEグループ等にトライアル案内を展開。
4. トライアル終了前にリマインド → 継続課金へ誘導。

### 7.3 紹介（リファラル）
- 満足したチーム・保護者が他チームに紹介。
- 「紹介で1ヶ月無料」等のインセンティブを検討。

### 7.4 補助チャネル：YouTube／SNS
- YouTube公式動画（32本）の概要欄・動画内にアプリ導線を設置 → 全国の検索流入を受動的に獲得。
- Instagram／TikTok のチアコミュニティで認知拡大。
- ※ 主軸はあくまで70チーム直接。SNSは将来の拡大用。

## 11. リスクと対策

| リスク | 内容 | 対策 |
|---|---|---|
| 無料版で満足され転換しない | 無料版が「十分」だと誰も課金しない | 進捗トラッキングを有料の核に。体験期限型トライアルで「記録への愛着」を作る |
| クライアント側ペイウォールの回避 | HTML/JSは誰でも読めて課金を強制できない | MVPは「正直に払う層」を見るのが目的なので許容。フェーズ4で認証導入 |
| 決済インフラの負担 | 個人月額課金は自動課金の仕組みが必要 | フェーズ1〜3はトライアルコード＋手動課金管理。売れてからStripe投資 |
| 単一チャネル依存 | 70チーム＝監督1人の稼働に依存 | YouTube/SNS・紹介を補助チャネルに育てる |
| 監督の稼働限界 | 出張で多忙、販促に時間を割けない | 現場提案を「チラシ＋QRを渡すだけ」に極限まで簡素化 |

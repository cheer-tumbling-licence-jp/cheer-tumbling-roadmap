## 2. OAuth トークン失効時の再認証（3分）

`youtube/launchd.log` に `invalid_grant: Token has been expired or revoked` が出たら：

```bash
rm /Users/don/cheer_tumbling_app/youtube/token.json
cd /Users/don/cheer_tumbling_app/youtube
python3 upload_videos.py --limit 1
```

→ ブラウザが自動で開く → `cheernicpro@gmail.com` で承認 → 2 段階認証コード入力 → 「許可」

完了後、token.json が新規生成され、その日の launchd は問題なく動く。

**注意**：このトークン失効は数日〜数週間ごとに起こり得る（Google の Testing 状態の仕様）。CEO が「再認証してください」と指示してきたらすぐ対応する。

## 3. プレミアム会員の手動切替（リリース初期の運用）

監督がメールで「プレミアム申込み」を受けたら、以下の手順で会員フラグを切り替える。

### 3-1. お支払い確認

申込メール（ユーザーから cheernicpro@gmail.com 宛）を確認 → 銀行口座 / PayPay で入金確認。

### 3-2. Firebase Console で plan を premium に変更

1. https://console.firebase.google.com/project/cheer-tumbling-roadmap/firestore を開く
2. 左の「データ」タブで `users` コレクションを開く
3. 該当ユーザーのドキュメント（UID は申込メールに記載された Google アカウントから特定）を探す
4. `plan` フィールドを `'free'` から `'premium'` に書き換える（フィールドがなければ追加）
5. 保存

→ ユーザーが次にアプリを開くと全動画が解放される（または、ユーザーに「リロードしてください」と返信）。

### 3-3. ユーザーへの完了通知

返信メールテンプレ：
```
〇〇 様

この度はプレミアムプランへのお申し込み、誠にありがとうございました。
入金を確認しましたので、本日よりプレミアム機能を解放いたしました。

次回アプリを開いていただくと、全動画が視聴可能になっております。
（変化が見えない場合は、ページを再読み込み / 強制リロード Cmd+Shift+R をお試しください）

引き続きどうぞよろしくお願いいたします。

一般社団法人 チアタンブリング協会
中村祐介
```

### 3-4. 解約の場合

ユーザーから解約申し出を受けたら、当月末まではプレミアム機能を維持し、翌月 1 日に `plan: 'free'` に戻す。

## 4. 新動画リリースの手順（重要・週次運用）

### 4-1. Google Drive に新動画をアップロード

`/Users/don/Library/CloudStorage/GoogleDrive-cheernicpro@gmail.com/マイドライブ/アプリ動画 2026/` に動画ファイルを置く。

### 4-2. CEO に「新動画追加して」と依頼

CEO は以下を実行：
- `youtube/video_manifest.py` にエントリ追加（タイトル・本文・タグ）
- `python3 youtube/video_manifest.py` で manifest.json 再生成
- 翌朝の launchd で自動アップロード（または手動 `python3 upload_videos.py --limit 6`）
- アップロード完了後、CEO が `index.html` に youtubeId と releaseDate を紐付け

### 4-3. releaseDate の設定（CEO が自動で書く）

新規 variant 動画には `releaseDate: 'YYYY-MM-DD'`（今日の日付）を付ける。
これで7日間は誰でも視聴可、7日後はプレミアム会員のみ。

### 4-4. 既存ユーザーへの通知（オプション）

新動画リリース後、SNS やメール一斉送信で「新動画追加しました」を告知すると課金転換率が上がる。

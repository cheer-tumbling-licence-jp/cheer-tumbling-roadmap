UI PROPOSAL

ナビゲーション刷新の3案

タンブリング技・トレーニング技 ＝ メイン感／練習メニュー・成長記録・練習プログラム ＝ カラム色違いで個人ツール感

監督ご指示「タンブリング技・トレーニング技を少し大きくしてメイン感／練習メニュー・成長記録・練習プログラムはカラム色を変えて違うメニュー感」を満たす3案を作成しました。各案のリンクから実画面を確認できます。

CASE A

サイズ差分強調型

既存の横並び1行レイアウトを維持したまま、メイン2タブだけパディング・フォントを増やし、サブ3タブにそれぞれカラムカラーを与える。最も少ない変更で監督指示を素直に達成。

+ 既存ユーザーの操作慣れを完全に維持

+ スマホ縦でも崩れにくい（1行 or 2行で折り返し）

− 「2グループに分かれている」意図はやや控えめ

★ CEO 推奨
 CASE B

階層化型（メインカード+サブピル）

メイン2タブを大きな2分割カード（横並びグラデ）として独立させ、その下に「個人ツール」ラベル＋3つのカラーピルを配置。意図が視覚的にはっきり伝わる。

+ メイン2つの存在感が最大

+ サブ3つの「個人ツール感」が明確

− 縦に2段になり、初期表示で他要素が下がる

表現リッチ案
 CASE C

「学ぶ／使う」明示型

上段「📚 学ぶ・観る」＋メイン2タブ、下段「🎯 個人ツール」＋サブ3タブ（カラム色違い）の2セクション分離型。最も初学者にやさしく、機能の意図がアプリ全体で揃う。

+ 機能の意図が言葉でも明示される

+ 将来タブが増えても整理しやすい

− 画面が縦に長くなる（特にモバイル）

構造重視案
CEO 見解：監督の意図「メイン感 + メニュー感」は 案A で過不足なく満たせます。案Bと案Cはより踏み込んだ階層化で、現状の操作慣れを多少リセットする代わりに「2グループ」の意図が強く伝わります。
選んでいただいた案をベースに、本番 index.html に正式反映します。「組み合わせて」「サブの色だけ案Cにして」などの折衷指示も受け付けます。

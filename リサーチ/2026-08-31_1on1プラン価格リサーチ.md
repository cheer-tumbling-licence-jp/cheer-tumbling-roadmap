## 4. 競合状況：オンライン・タンブリング指導は「空白市場」

「アクロバット タンブリング オンライン指導 月額 動画添削」で検索した結果、**サブスク型でオンライン添削を提供する競合は見つかりませんでした**。ヒットしたのは全て**対面**の教室（バク転パーソナル教室、バクトレ、Jump UP、日野アクロバット教室、RainbowAcrobat 等）です。

**この意味するところ**：

1. **比較される相手が対面教室しかない** → ユーザーの価格基準は「1回 ¥6,000〜9,000」。月額¥7,500は「1回分より安い」と映り、**むしろ品質を疑われる水準**。
2. 価格を下から叩く直接競合が存在しない → **値下げ圧力がゼロ**。プライスリーダーとして自分で相場を決められる立場。
3. 「安さ」で戦う理由が一つもない。**安さは差別化になっておらず、単に利益を捨てているだけ**。

## 5. もう一つの構造問題：¥4,500 と ¥7,500 の価格差が壊れている

| プラン | 価格 | 差 | 内容差 |
|---|---|---|---|
| トレーニング指導 | ¥4,500 | — | 添削月20本 |
| 完全1on1 | ¥7,500 | **+¥3,000（1.67倍）** | 添削**無制限**＋LINE24h＋ビデオ通話＋解析レポート |

**たった +¥3,000 で、無制限添削・ビデオ通話・専用LINE・解析レポートが全部つく。**

結果として起きること：

- 検討者は全員 ¥7,500 を選ぶ（¥4,500が割高に見える）
- = **一番労力のかかるプランに顧客が集中する**
- = 会員が増えるほど中村さんの時間が枯渇し、品質が維持できなくなる

**上位プランは「選ばれにくいが利益率が高い」設計であるべき**です。今は真逆になっています。

### 案C：¥29,800/月（強気・プロ選手向け）

## 7. 「無制限」は必ずやめてください（値上げ以上に重要）

現行の「動画添削 無制限」には次の構造的欠陥があります。

1. **原価が読めない** — 会員によって月5本の人と月50本の人がいて、収益性が10倍変動する
2. **値上げしても解決しない** — ¥19,800にしても、月60本送ってくる会員が1人いれば時給は破綻する
3. **品質を下げる圧力になる** — 数をこなすため1本あたりの添削が雑になる
4. **辞めどきが作れない** — 「無制限と言ったのに」というクレームの温床

**月30本上限＋超過¥500/本**にすれば、原価が固定でき、かつ**熱心な会員からは追加収益が上がります**。上限を「30本」に設定するのは、実際に30本を超える会員はごく少数で、大半のユーザーには実質無制限に感じられるためです。

## 8. 値上げの実務手順

### 8-1. 既存契約者の扱い（グランドファザリング推奨）

Stripeのサブスクは、**Price IDを差し替えない限り既存契約者は旧価格のまま継続**されます。

- 新価格のPrice IDを新規作成 → LP・アプリのチェックアウト導線だけ差し替え
- **既存の¥7,500契約者はそのまま¥7,500で継続**
- 案内文：「◯月◯日より新規申込は¥19,800となりますが、すでにご契約中の方は現在の料金のまま継続いただけます」
- 効果：既存会員の解約を防ぎつつ、「今入れば安い」という駆け込み需要を作れる

### 8-2. 変更が必要なファイル

| ファイル | 箇所 |
|---|---|
| `landing.html` | 944-957行（完全1on1カード）／トレーニング指導カードも要検討 |
| `index.html` | アプリ内プラン表示 |
| `stripe-checkout.js` | Price ID |
| `functions/index.js` | Price IDマッピング |
| `functions/scripts/setup-stripe-products.js` | 商品定義 |
| `specified-commercial.html` | **特定商取引法表記（価格記載は法定義務）** |
| `OPERATIONS.md` | セクション2の料金表 |
| `trifold.html` / マーケティング配下PDF | 販促物の価格 |

### 8-3. 値上げ告知の推奨タイミング

1. **告知〜値上げまで2〜3週間**の猶予を置く（駆け込み申込を取る）
2. Instagram・LINE公式で「◯月◯日より価格改定。それまでの申込は旧価格で継続」
3. 値上げと**同時に**内容を増やす（ビデオ通話 月1回→月2回）。「値上げ」ではなく「プラン強化」として提示する

## 10. リスクと対策

| リスク | 評価 | 対策 |
|---|---|---|
| 既存会員の解約 | 低 | グランドファザリングで旧価格継続 |
| 新規が取れなくなる | 中 | 無料相談15分を入口に維持。価格は相談後に提示する導線も可 |
| 「高い」と言われる | 低 | 対面1回¥7,700という比較材料を明示。LP上で対面との比較表を出す |
| 品質期待が上がる | 中 | 解析レポートのフォーマットを標準化し、毎回の品質を安定させる |

**最大のリスクは値上げではなく、現状維持です。** 会員が5名に増えた時点で月25〜50時間の個別対応が発生し、¥37,500の売上に対して中村さんの本業（協会運営・教本制作・BULLETS・Gym plus）が圧迫されます。**安い価格は、成功したときに一番きつくなります。**

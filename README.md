# Cheer Tumbling Roadmap

チアリーディング指導者向けタンブリング練習ロードマップアプリ。
ブラウザのみで動作する自己完結型 HTML（外部ライブラリは Sortable.js のみ）。

## 機能

- **タンブリング技** 55 件をレベル別（基礎運動〜上級+）で表示
- **トレーニング** 25 件をカテゴリ別（体幹・筋力・ジャンプ・柔軟）で整理
- **練習メニュー**作成（ドラッグ並び替え・印刷・複製）
- **ツリー（系譜図）表示**で技の依存関係を可視化
- **編集モード**で文言・並び・レベルを直接書き換え（ブラウザ自動保存）
- レベル絞り込み・全文検索・YouTube チュートリアル動画リンク

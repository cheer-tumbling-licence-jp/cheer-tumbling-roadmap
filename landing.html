What is this?

これは何のアプリ？

「ウォームアップから後方宙返りまで」のすべての技を、習得順に並べた指導者・選手のための学習アプリです。各技には動画解説・前段階の必須スキル・つまずきやすいポイント・推奨トレーニングがついていて、独学でも体系的に進められます。

Features for You

個人で使う機能

📚

技ロードマップ閲覧

33 技 + 44 トレーニングを、レベル順・系譜図（ツリー）で閲覧。各技に動画・ポイント・よくあるミスを掲載。

📋

練習メニュー作成

技とトレを組み合わせて、自分用の練習メニューを保存。秒数・回数も指定可能。チームメンバーへリンクで共有できます。

📈

選手ごとの進捗記録

選手ごとに「習得中／合格」を技ごとに記録。指導者は全員の進捗を俯瞰でき、選手は自分の到達度が一目瞭然。

⚙️

練習プログラム自動生成

人数・時間・目標技を入力すれば、ウォームアップ→補強→技練習までの構成を自動提案。準備の手間を大幅短縮。

Features for Coaches

コーチ機能（指導者向け）

コーチダッシュボード

選手の招待・課題配布・提出物確認をひとつの画面で管理。QRコード／LINE共有で選手を簡単に招待。チームごとの招待コードも自動発行。

課題配布

スキル＋トレを組み合わせて、選手1人〜全員に課題を配信。期限・メッセージも添付可能。「来週はこれを練習して」が一瞬で送れます。

🎬

動画提出＋コーチ添削

選手は完了報告に動画リンクとコメントを添付。コーチはテキストで返信＆指導。LINE / Google ドライブ / YouTube どの形式でもOK。

📊

進捗ヒートマップ

選手 × スキルのマトリクスで、誰がどこまで進んだか色分け表示。「未提出」「未返信」「返信完了」が一目で分かり、指導の優先順位を整理。

How to start

3 ステップで始められます

1

スマホのホーム画面に追加

iPhone / iPad の Safari でアプリを開き、共有ボタン（□に↑）→「ホーム画面に追加」を選ぶだけ。Android は Chrome のメニューから「ホーム画面に追加」。

📱 アプリのように全画面で起動できます（毎回URL入力不要）
2

Google または メールで登録

「Googleで無料トライアルを始める」を押せば 1 タップで開始。Google アカウントがない人は「メールアドレスで登録」も選べます。

⏱ 1分で完了・クレジットカード不要・30日間すべての機能が無料
3

練習開始

「タンブリング技」タブから興味のある技を選ぶ → 動画を見て、前段階の必須スキルとよくあるミスを確認 → 「練習メニュー」で自分専用のメニューを組み立てる → 「成長記録」で習得状況を記録。

🎯 まず「バク転」「ロンダート」「ロンバク」などの主要技から見るのがおすすめ

FAQ

よくある質問

本当に 30 日間すべて無料ですか？

はい。クレジットカード登録も不要で、30日間すべての機能を試せます。期間終了後の自動課金もありません（明示的に有料プランを選んだ場合のみ課金されます）。

Google アカウントがありません。登録できますか？

はい。「メールアドレスで登録 / ログイン」ボタンから、任意のメールアドレスとパスワードで登録できます。

動画はオフラインでも見られますか？

動画は YouTube から配信されるため視聴時に通信が必要です（オフライン視聴は YouTube アプリの保存機能をご利用ください）。技の解説テキスト・ポイント・進め方は、一度開けばオフラインでも閲覧できます。

機種変更したらデータは消えますか？

ログインしていれば、練習メニュー・進捗記録などはクラウドに自動保存されます。機種変更後、同じアカウントでログインすれば全データが復元されます。

子どもや初心者でも安全に使えますか？

各技に「前段階の必須スキル」と「補助・マット使用などの安全条件」を明記しています。指導者・保護者の付き添いの下、段階を飛ばさずに進めることを前提に設計されています。

複数の選手を 1 つのアカウントで管理できますか？

はい。コーチプランなら最大10名（追加￥100/人）、コーチプラスなら無制限です。各選手は招待コードで参加し、コーチダッシュボードから一元管理できます。

選手側にも料金はかかりますか？

かかりません。選手はコーチの招待コードを使えば完全無料でアプリを利用できます（課題確認・完了報告・動画提出など全機能）。コーチが課金してくれている形になります。

コーチ機能を実際に試してから決められますか？

はい。新規登録すると30日間すべてのコーチ機能（課題配布・動画添削・進捗ヒートマップ）を試せます。期間中は選手を招待して実運用も可能です。

選手が出した動画はどこに保存されますか？

選手は自分の好きなサービス（LINE / Google ドライブ / YouTube / Vimeo 等）に動画を保存し、その共有リンクを提出します。アプリ自体は動画を保管しないので、選手のプライバシーが守られます。

個人モードから途中でコーチに招待されることはできますか？

できます。個人モードで作った練習メニュー・進捗記録はそのまま残ったまま、コーチからの招待コードで「選手モード」が追加されます。

チーム単位の導入・法人契約はできますか？

準備中です。70 チーム規模での導入実績を目指して仕組みを整えています。お問い合わせは協会（cheernicpro@gmail.com）までご連絡ください。

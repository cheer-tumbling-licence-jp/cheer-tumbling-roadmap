# 訪問先プロモーション台本（チア・体操・バク転教室向け）

> 目的：監督が指導訪問・体験会・教室見学の場で、iPad/iPhone を見せながら自然に「チア タンブリング ロードマップ」を紹介し、その場でホーム画面追加 & 30日無料トライアル登録まで完了させる。

---

## 共通：話す前の準備

- 監督の iPad/iPhone で **LP（https://cheer-tumbling-licence-jp.github.io/cheer-tumbling-roadmap/landing.html）** をブックマーク or ホーム画面に固定
- アプリ本体も**ホーム画面に追加済み**にしておく（実演用）
- 印刷したチラシ（後述：flyer_a4.html）を 3〜5 枚と、名刺カード（business_card.html）を 10 枚は常備
- 自分のアカウントは事前にログアウト or テスト用ダミーアカウントを用意（新規登録の流れを見せるため）

---

## パターンA：30秒〜1分（廊下での立ち話、保護者との挨拶など）

**話す相手**：保護者 / 他チームの指導者 / 知人の指導者

```
最近、指導者・選手向けにタンブリングのアプリを作ったんです。
33個の技と44のトレーニングを動画付きで体系化してて、
練習メニューも子供ごとの進捗も全部記録できます。
30日無料で試せるので、QR 読んでもらってもいいですか？
```

→ 名刺カードを渡して終了。**深追いしない**。
→ 興味を持った相手だけがその場で QR を読み取る or 後日 LP にアクセスする。

---

## パターンB：3〜5分（教室見学・体験会の合間）

**話す相手**：教室代表者 / 指導コーチ / 中学高校の部活顧問

### Step 1（30秒）— ニーズ確認

```
「タンブリング指導で、いつも悩むのは
"どの順序で技を教えれば安全に進められるか"と、
"選手1人1人の到達度をどう記録するか"じゃないですか？」
```

→ 相手の反応を待つ（うなずき・「そうそう」が出れば次へ）

### Step 2（1分）— LP を見せる

iPad で LP のヒーロー部分を見せながら：

```
「これ、その2つを解決するために作ったアプリです。
指導歴18年の経験を全部、技ロードマップと
練習メニュー機能に落とし込んでます」
```

→ スクロールして「4つの機能カード」を見せる
→ それぞれ 5 秒ずつ指で示しながら：

- 「これが**技ロードマップ**。33技+44トレが全部動画付きで」
- 「これが**練習メニュー作成**。技とトレを組み合わせて自分用に」
- 「これが**選手ごとの進捗記録**。誰がどこまで進んでるか一目で」
- 「これが**練習プログラム自動生成**。人数と時間入れれば組んでくれる」

### Step 3（1分）— 使い方デモ

実機アプリ本体を開いて：

```
「実際に動いてるのお見せしますね」
```

- 「タンブリング技」タブで **バク転**の詳細を開く
- 動画を 5 秒だけ再生（音はミュート可）
- 「ロンダート」「ロンバク」と前段階の必須スキルが繋がっていることを示す
- 「練習メニュー」タブで、何か1つメニュー例を見せる

### Step 4（30秒〜1分）— その場でホーム画面追加

```
「30日間全機能無料で試せるんで、
よかったら今ここでホーム画面に追加してもらえますか？
QR読み取って Safari で開いて、共有 → ホーム画面に追加で1分です」
```

→ 相手の iPad/iPhone を借りて一緒にやる（最重要）。
→ ホーム画面にアイコンが出た瞬間「これでもう普通のアプリと同じです」と一言。

### Step 5（締め）

```
「使ってみて気になるとこあれば、いつでも連絡ください。
LINE でも メールでも大丈夫です」
```

→ 名刺カードを渡す。

## パターンC：10〜15分（正式プレゼン・新規導入相談）

**話す相手**：チーム代表者 / 教室運営者 / 法人契約検討者

### Step 1（2分）— なぜ作ったか

監督自身のストーリーを語る：

```
「私は元体操選手で、今は18年チアタンブリングの指導をしています。
ずっと感じてたのは、

  - "技の正しい順序" が指導者によってバラバラで、
    結果として安全な指導と危険な指導が混在してること
  - 選手の進捗を紙やExcelで管理してて、引き継ぎや
    複数指導者間での共有が大変なこと
  - 動画教材は YouTube に散らばっていて、
    "この技の前にこれをやるべき" という体系が
    まとまっていないこと

これを解決するために、協会公式のアプリとして
"チア タンブリング ロードマップ" を作りました」
```

### Step 2（3分）— LP を見せながら機能説明

パターンB の Step 2 と同じ流れだが、丁寧に：

- 4つの機能カードを 1 つずつ詳しく
- 各機能で「監督の指導現場でどう使うか」を例示
  - 「練習メニュー作成 → 月曜の練習メニューを月初に組んで、毎週使い回す」
  - 「進捗記録 → 中3〇〇さんは△△まで合格、◇◇は習得中、と俯瞰できる」
  - 「プログラム自動生成 → 体験会のスケジュール組むときに使える」

### Step 3（3分）— 実機デモ

パターンB の Step 3 を拡張：

- バク転を選んで、**つまずきポイント**や**よくあるミス**まで丁寧に見せる
- 練習メニューを実際にその場で 1 つ作って見せる
- 進捗記録を 1 名分、その場で記入してみせる

### Step 4（2分）— 監督の運用イメージを聞く

```
「もし御チームで導入するとしたら、
誰が・いつ・どう使うイメージですか？
例えば指導者 5 名・選手 30 名の場合、
全員にアカウント作ってもらう感じか、
指導者だけ使ってその場で見せる感じか」
```

→ 相手の運用イメージを引き出す
→ それに合わせた使い方を逆提案

### Step 5（2分）— 料金と次のステップ

```
「個人は 30 日無料でその後の有料プランは
今月中に最終決定予定です。
チーム単位での導入も準備中で、
御チームの規模だと法人プランの対象になります。

まずは指導者の方だけでも 30 日無料で触ってみて、
2 週間後ぐらいに改めてフィードバックいただけますか？」
```

→ 名刺カードとチラシを渡す。
→ 後日連絡のため、相手のメアド or LINE を聞く。

### Step 6（締め）

```
「協会としても、安全で体系的な指導を全国に広げたいので、
御チームでの導入は本当にありがたいです。
何かあればいつでもご相談ください」
```

## よくある質問と回答（虎の巻）

### Q1：「無料って本当？何か裏あるんじゃない？」
A：「クレジットカード登録も不要で、30日完全無料です。期間後の自動課金もないので安心してください。気に入ったら有料プランを選んでもらう仕組みです」

### Q2：「うちの指導者全員 Google アカウント持ってないかも」
A：「メールアドレスでも登録できます。Gmail じゃなくても、何のメアドでも大丈夫です」

### Q3：「動画は何本くらいあるの？」
A：「現時点で 44 本、今月中に 60 本以上になる予定です。基礎運動から後方宙返りまで全部入ってます」

### Q4：「他のアプリと何が違うの？」
A：「YouTube は動画が散らばってて系統だってないですよね。これは"前段階の必須スキル"が技ごとに明記されてて、選手の進捗管理も一緒にできる。指導現場でそのまま使える点が違います」

### Q5：「機種変更したらデータ消える？」
A：「ログインさえしてれば、メニューも進捗も全部クラウドに保存されるので消えません。新しい機種で同じアカウントでログインすればそのまま続きから使えます」

### Q6：「監督が作ったの？技術詳しいの？」
A：「タンブリングの内容は私が監修してて、システム開発は信頼できるパートナーと進めてます。週1で改善続けてるので、要望があればすぐ反映できる体制です」

### Q7：「うちのチームの選手の動画を入れることできる？」
A：「現状は協会公式の動画だけですが、チーム専用の動画追加機能は導入チーム向けに開発予定です。要望があれば優先的に対応します」

### Q8：「料金はいくらになる？」
A：「個人プランは月数百円〜千円程度を予定してます。法人プランは選手数で変動する仕組みを検討中です。まずは無料期間で価値を感じてもらって、料金が決まったら改めてご案内します」

## クロージング3原則

1. **その場で行動させる**：見せて終わりではなく、QR読み取り→ホーム画面追加→ログインまでその場で完了させる
2. **押し付けない**：「30日無料なので、ダメだったら使わなくて全然OK」のスタンス。プレッシャー無しが信頼を生む
3. **次の接点を作る**：名刺カードを必ず渡す + 「2週間後フィードバック聞かせて」など次回の話に繋げる
